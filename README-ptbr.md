# Acordeão de Perguntas Frequentes

Um componente de acordeão de perguntas frequentes simples e interativo, construído como um desafio do Frontend Mentor.

## Descrição

Este projeto é uma solução para o desafio "Acordeão de perguntas frequentes". O objetivo principal foi criar um componente funcional que exibe uma lista de perguntas frequentes e permite ao usuário expandir ou recolher cada pergunta para revelar sua resposta. O projeto foca no uso de **JavaScript** para lidar com os eventos de clique e alternar a visibilidade do conteúdo, juntamente com CSS para transições suaves e rotações de ícones.

## Tecnologias Usadas

* **HTML5:** Para criar a estrutura semântica das perguntas e respostas.
* **CSS3:** Para estilizar o componente, incluindo um layout responsivo, estilos de fonte e os efeitos visuais de expansão e recolhimento do conteúdo.
* **JavaScript:** A tecnologia-chave usada para implementar a funcionalidade interativa do acordeão. Ele escuta os eventos de clique nos cabeçalhos das perguntas e adiciona ou remove dinamicamente uma classe para mostrar ou ocultar a resposta correspondente.

## Instalação

Este é um projeto de frontend estático, então não é necessária uma configuração complexa. Para obter uma cópia local, basta seguir estes passos:

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/hangtime319/faq-accordion.git](https://github.com/hangtime319/faq-accordion.git)
    ```
2.  Abra o arquivo `index.html` no seu navegador da web preferido para visualizar o projeto.

## Uso

Este projeto serve como uma vitrine de um componente de acordeão reutilizável. Os usuários podem clicar em qualquer pergunta para:
* **Expandir** a pergunta e revelar sua resposta.
* **Recolher** a pergunta e ocultar sua resposta, clicando nela novamente.

## Funcionalidades

* **Funcionalidade de Acordeão:** As perguntas podem ser expandidas e recolhidas para mostrar/ocultar suas respostas.
* **Animações Suaves:** A transição de recolhido para expandido é suave e visualmente agradável.
* **Ícones Interativos:** O ícone de mais/menos ao lado de cada pergunta gira para indicar o estado do item do acordeão.
* **Design Responsivo:** O componente é otimizado para ficar ótimo em vários tamanhos de tela.
