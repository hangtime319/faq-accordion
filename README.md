# FAQ Accordion

A simple and interactive FAQ accordion component, built as a challenge from Frontend Mentor.

## Description

This project is a solution to the "FAQ accordion" challenge. The main goal was to create a functional component that displays a list of frequently asked questions and allows the user to expand or collapse each question to reveal its answer. The project focuses on using **JavaScript** to handle the click events and toggle the visibility of the content, along with CSS for smooth transitions and icon rotations.

## Technologies Used

* **HTML5:** For creating the semantic structure of the questions and answers.
* **CSS3:** For styling the component, including a responsive layout, font styles, and the visual effects of expanding and collapsing the content.
* **JavaScript:** The key technology used to implement the interactive accordion functionality. It listens for click events on the question headers and dynamically adds or removes a class to show or hide the corresponding answer.

## Installation

This is a static frontend project, so no complex setup is required. To get a local copy, simply follow these steps:

1.  Clone the repository:
    ```bash
    git clone [https://github.com/hangtime319/faq-accordion.git](https://github.com/hangtime319/faq-accordion.git)
    ```
2.  Open the `index.html` file in your preferred web browser to view the project.

## Usage

This project serves as a showcase of a reusable accordion component. Users can click on any question to:
* **Expand** the question and reveal its answer.
* **Collapse** the question and hide its answer, by clicking on it again.

## Features

* **Accordion Functionality:** Questions can be expanded and collapsed to show/hide their answers.
* **Smooth Animations:** The transition from collapsed to expanded is smooth and visually appealing.
* **Interactive Icons:** The plus/minus icon next to each question rotates to indicate the state of the accordion item.
* **Responsive Design:** The component is optimized to look great on various screen sizes.
